# Portico 0.2.2

A fix release after the re-read of the project (write-up 36). Portico
behaves as in
[0.2.0](https://github.com/marco-fabbri/portico/blob/v0.2.2/docs/releases/v0.2.0.md),
whose requirements and known limits still apply, with the fixes below.

## What changed

- **The public path refuses a path it cannot vouch for.** The deny list
  matched the decoded path while the proxy forwarded the raw one: a
  local-login request with an encoded slash, dot or control byte
  (`%2F`, `%2E`, `%00`) passed the rule and reached Prism Central byte
  for byte. Such a path is now refused with `deny-encoded-path` before
  the session check.
- **A bare token never reaches the access log.** The log named the
  first word of `Authorization`; a value without a scheme was the
  credential itself. Only known schemes are named, anything else is
  `other`.
- **The exposure switch edits the public block only, and plain HTTP
  off the loopback never starts.** A configuration whose public block
  had no TLS lines got the pair written into the internal block on the
  switch to direct; Portico now refuses that file, and `serve` refuses
  to start a public listener off the loopback without a pair.
- **A Prism Central error while waiting for a task no longer creates
  the object twice.** A 500 on the task poll was taken as the step's
  failure and the step ran again while the task still ran; the poll
  goes on instead.
- **Disconnect deletes the group's role membership in the tenant's
  project only**, so a group the MSP made by hand keeps the roles it
  holds elsewhere.
- **Network objects are adopted only inside the tenant's project and
  VPC, and never by name after a delete.** A tenant that deleted its
  subnet and made one of the same name no longer sees it adopted by
  Retry network and deleted at Disconnect; an object found without its
  project is repaired on every path.
- **`PUT /api/v1/settings` carries the tenant address pool**, keeps it
  when omitted, validates it and refuses a change with 409 while a
  ready network uses the pool, as the setup page does. Before, a GET
  then a PUT of the same body reset a custom pool.
- The install guide names no version; the README, SECURITY and the
  design are at the current release; the code and tests carry
  documentation addresses instead of the test site's.

## Upgrading from 0.2.x

Nothing to do: the upgrade is in place (install guide, "Updating"). An
appliance whose process settings were edited by hand to drop the
public `tls` lines must have them back (empty in tunnel mode) before
the first start of 0.2.2.

## Measured on

The unit tests of each fix (`go test ./...`), against the fakes of
Prism Central and Keycloak. The proxy rules are to be re-measured on
pc.7.6 with the probe script when the appliance is next rebuilt, and
write-up 06 updated with what Prism Central does with an encoded path
that reaches it directly.
