# Fonts

Red Hat Display and Red Hat Text (variable fonts, weights 400 to 700),
the typefaces Keycloak's PatternFly theme uses on the login page, so the
admin UI and the MSP login page share one voice. Taken from the Keycloak
26.3 PatternFly 5 bundle; licensed under the SIL Open Font License 1.1
(`OFL.txt`, copyright Red Hat, Inc., reserved font name "Red Hat"). The
admin UI's content security policy allows no external origin, so the
files ship inside the binary (78 KB in all).
